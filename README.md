# PhScan - 下一代端口风险扫描器

<div align="center">

**PhScan** 是一款专为企事业单位内部安全审计设计的轻量级端口扫描与风险评估工具。
基于 **Go + Wails + Vue** 构建，提供高性能的并发扫描引擎与现代化的桌面图形界面。

<br>

**⚠️ 免责声明：本工具仅用于已获明确授权的资产防御性审计。严禁用于未授权扫描或攻击行为。**

</div>

---

## ✨ 核心特性

*   **🛡️ 防御性审计定位**：专注于 TCP Connect 扫描与只读协议识别（Banner Grabbing），**不包含**任何漏洞利用、RCE、弱口令爆破或 DoS 功能。
*   **⚡ 高性能并发引擎**：纯 Go 编写核心扫描逻辑，支持可控并发（默认 16，最大 256），毫秒级超时控制，快速覆盖大规模网段。
*   **🎯 智能端口策略**：
    *   **全端口扫描** (1-65535)
    *   **高风险模式**：内置常见高危端口及变种端口（如 Docker API, Redis, Memcached 等）。
    *   **自定义模式**：支持灵活的端口范围输入。
*   **🔍 深度协议识别**：内置 HTTP/HTTPS, SSH, Redis, MySQL, PostgreSQL, Memcached 等多种协议的只读探针，自动识别服务版本线索。
*   **📊 风险规则引擎**：本地静态规则库，关联 CVE 编号与 CVSS 评分，自动标记暴露风险（需人工确认版本）。
*   **🖥️ 现代化桌面应用**：基于 Wails 框架，无需安装浏览器即可运行，提供流畅的 Vue 前端交互体验。
*   **📝 多格式报告导出**：支持 JSON, CSV, Markdown 三种格式导出，方便集成到现有运维流程。

## 🏗️ 架构与技术栈

| 组件 | 技术 | 说明 |
| :--- | :--- | :--- |
| **后端核心** | Go (Golang) | 扫描引擎、风险匹配、报告生成、任务管理 |
| **桌面框架** | Wails v2 | Go 与 Web 技术的桥梁，打包为原生 exe |
| **前端界面** | Vue 3 + Vite | 响应式 UI，实时日志流，进度可视化 |
| **数据存储** | 内存/文件 | 无数据库依赖，结果即时导出 |

### 🚀 快速开始：直接使用编译好的程序 (推荐)

1. 前往 [Releases](../../releases) 页面下载最新版本的 `PhScan.exe` (Windows)。
2. **注意**：Windows 用户需确保系统已安装 [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (Win10/11 通常自带)。
3. 双击运行，勾选“我确认目标属于已授权资产”即可开始扫描。
